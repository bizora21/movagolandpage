«Guarde o código de rastreio.» Quase toda a gente ouve esta frase quando envia uma encomenda, mas poucos sabem exatamente para que serve, onde ele está e o que fazer quando algo corre mal. Neste guia explicamos tudo em linguagem simples, para que nunca mais fique sem saber onde está a sua encomenda.

Resposta rápida: o que é um código de rastreio?

O código de rastreio é um identificador único que a transportadora atribui a cada encomenda. Com ele, quem envia e quem recebe consultam o estado da encomenda e o percurso já feito, sem precisar de ligar para ninguém.

Para que serve o código de rastreio?

  • Saber onde está a encomenda: o estado muda à medida que ela avança (recebida, em trânsito, pode levantar, entregue).
  • Provar que a encomenda foi enviada: o código liga o seu envio a um registo, o que ajuda se houver algum problema.
  • Combinar o levantamento: o destinatário sabe quando a encomenda chegou à estação de destino.
  • Evitar chamadas e deslocações: em vez de perguntar «já chegou?», consulta-se o estado online.

Onde encontro o meu código de rastreio?

Quando a encomenda é recebida na estação, quem a envia recebe um talão. O código de rastreio está nesse talão. Em sistemas como o da MOVAGO, o código tem um formato parecido com TR-2026-10-00001: umas letras, o ano, o mês e um número de série.

Se é o destinatário e não tem o talão, peça o código a quem enviou. É o mesmo código para os dois.

Dica que evita muitos problemas

Assim que receber o talão, tire uma fotografia nítida e envie-a ao destinatário. Se o papel se molhar ou se perder, o código continua a salvo no telemóvel.

Como usar o código de rastreio, passo a passo

  1. Abra a página de rastreio no telemóvel ou no computador.
  2. Escreva o código exatamente como está no talão, com letras, hífenes e zeros no sítio certo.
  3. Consulte o estado e o percurso. Volte a consultar sempre que quiser.

Não precisa de criar conta nem de instalar nenhuma aplicação.

O que fazer se o código «não existe»?

  • Confira cada caracter. Confundir a letra O com o número zero é o erro mais comum.
  • Espere um pouco se a encomenda acabou de ser enviada: o registo pode demorar a aparecer.
  • Peça ao remetente para confirmar o código no talão.
  • Contacte a estação indicada no talão, com o código à mão.

Perguntas frequentes sobre o código de rastreio

O código de rastreio é o mesmo para o remetente e o destinatário?

Sim. Os dois consultam o mesmo percurso com o mesmo código.

O código de rastreio mostra os meus dados pessoais?

Na página pública de rastreio da MOVAGO aparecem apenas o estado e o percurso da encomenda. Telefones, valores e fotografias não são mostrados.

Posso rastrear sem criar conta?

Sim. Só precisa do código.

Perdi o talão. E agora?

Peça o código a quem enviou a encomenda ou contacte a estação onde foi registada, indicando o nome e a data do envio.

Quanto tempo posso consultar o código?

Enquanto a encomenda estiver em curso e depois da entrega, o histórico serve de prova do percurso. Guarde sempre o talão até a encomenda ser entregue.
